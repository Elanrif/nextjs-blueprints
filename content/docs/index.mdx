## ✨ Points Forts

✅ **Pattern `{entity}`** — Répétable pour toute entité métier  
✅ **Type-safe** — TypeScript partout (Zod, React Query)  
✅ **Prêt à l'emploi** — Config, hooks, utilitaires inclus  
✅ **Performant** — Cache React Query, lazy loading, optimisations  
✅ **Maintenable** — Services centralisés, validation unifiée  
✅ **Sécurisé** — Validation client et serveur

## 🚀 Installation Express

```bash
# 1. Copier les dossiers
cp -r templates/{config,lib,hooks,types,utils} src/

# 2. Installer les dépendances
npm install @tanstack/react-query react-hook-form zod axios nuqs sonner

# 3. Configurer layout.tsx
# Ajouter: NuqsAdapter, QueryProvider, Toaster

# 4. Ajouter variables CSS TailwindCSS
# Voir Démarrage Rapide pour les détails
```

**Temps estimé :** 10-15 minutes

## 💡 Exemple : Créer une Entité `users`

### En 5 fichiers

1. **Types** — `lib/users/api/types.ts`
2. **Validation** — `lib/users/schemas/user.schema.ts`
3. **Service** — `lib/users/api/services/user.client.ts`
4. **Hooks** — `lib/users/api/queries/queries.client.ts`
5. **Mutations** — `lib/users/api/mutations.ts`

```tsx
// Puis dans votre page
"use client";

import { useUserList } from "@/lib/users/api/queries";

export default function UsersPage() {
  const { data, isLoading } = useUserList();

  return <Table data={data?.data} />;
}
```

## ❓ Questions Courantes

**Q : Je dois utiliser le template exactement comme présenté ?**  
R : Non ! C'est une structure de base. Adapte-la à tes besoins.

**Q : Puis-je ajouter d'autres librairies ?**  
R : Bien sûr ! Ajoute n'importe quelle dépendance. Le template n'est pas restrictif.

**Q : Comment gérer l'authentification ?**  
R : Il y a déjà un module `lib/auth`. Voir la doc pour plus de détails.

**Q : C'est quoi le pattern `{entity}` ?**  
R : Une structure réutilisable pour toute entité (users, products, etc). Voir [Entity Guide](/entity-guide).
