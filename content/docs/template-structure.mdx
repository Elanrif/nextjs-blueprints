## 📐 Architecture Générale

Le template est organisé autour d'une **architecture modulaire** où chaque entité (`{entity}`) suit le même pattern structuré. Cela permet une copie rapide et cohérente du design system dans n'importe quel projet.

## 🎯 Principes de Design

### 1. **Pattern `{entity}`**

Chaque module métier suit le même pattern pour garantir la cohérence :

- **API Layer** : Services, queries, mutations
- **Components Layer** : Formulaires, listes, vues
- **Schema Layer** : Validation avec Zod

### 2. **Séparation Client/Serveur**

```
api/queries/
├── queries.client.ts    → useQuery hooks côté client
└── queries.server.ts    → Fonctions async côté serveur

api/services/
├── {entity}.client.ts   → Appels API via Axios
└── {entity}.server.ts   → Accès direct base de données
```

### 3. **Configuration Centralisée**

Tous les configs critiques sont dans `config/` :

- ✅ Axios & interceptors
- ✅ Variables d'environnement
- ✅ Logger & monitoring
- ✅ Query client React Query

### 4. **Utilitaires Partagés**

- `lib/_/` : Utilitaires "privés" (gestion erreurs, images, composants base)
- `lib/` : Utilitaires publics (formatage, parsing, authentification)
- `hooks/` : Hooks React réutilisables

## 💡 Points d'Extension

### Ajouter une nouvelle entité

1. **Dupliquer le pattern** `lib/{entity}`
2. **Remplacer** `{entity}` par votre nom (ex: `users`, `products`)
3. **Adapter** les types et schémas
4. **Ajouter** les composants UI spécifiques

Exemple avec `users` :

```
lib/users/
├── api/
│   ├── types.ts
│   ├── queries/
│   ├── services/
│   └── mutations.ts
├── components/
│   ├── user-form.tsx
│   ├── user-table/
│   └── user-view-page.tsx
└── schemas/
    └── user.schema.ts
```

### Modifier les configurations

Les configs se propagent à travers les interceptors :

```typescript
// config/interceptors/auth.interceptor.ts
// Ajouter du token automatiquement
// Gérer les 401/403
```

## 🔄 Data Flow

```
┌─────────────────────┐
│  React Component    │
│   (page.tsx)        │
└──────────┬──────────┘
           │
┌──────────▼──────────────┐
│  React Query Hook       │
│  (useQuery/useMutation) │
└──────────┬──────────────┘
           │
┌──────────▼──────────────┐
│  Service Class          │
│  ({entity}.client.ts)   │
└──────────┬──────────────┘
           │
┌──────────▼──────────────┐
│  Axios Instance         │
│  (+ interceptors)       │
└──────────┬──────────────┘
           │
       Backend API
```
