## 🚀 Installation en 4 étapes

### Étape 1 : Copier les dossiers du template

```bash
# Depuis le répertoire du template
cp -r env config lib hooks types utils eslint.config.mjs tsconfig.json ../votre-projet-destination/src/
```

**Dossiers copiés :**

- `env/` - Variables d'environnement
- `config/` - Configurations Axios, API, interceptors
- `lib/` - Utilitaires, services, patterns entités
- `hooks/` - React hooks réutilisables
- `types/` - Types TypeScript globaux
- `utils/` - Utilitaires généraux
- `eslint.config.mjs` - Configuration ESLint
- `tsconfig.json` - Configuration TypeScript

---

## Étape 2 : Mettre à jour `src/app/layout.tsx`

Remplacez votre `layout.tsx` par cette structure :

```tsx
import { NuqsAdapter } from "nuqs/adapters/next/app";
import { Toaster } from "@/lib/_/components/ui/sonner";
import QueryProvider from "@/lib/_/components/layout/query-provider";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="fr">
      <body>
        <NuqsAdapter>
          <QueryProvider>
            <Toaster />
            {children}
          </QueryProvider>
        </NuqsAdapter>
      </body>
    </html>
  );
}
```

**Ce que cela configure :**

- `NuqsAdapter` → Gestion des paramètres URL
- `QueryProvider` → React Query pour le cache serveur
- `Toaster` → Notifications (Sonner)

## 📋 Configuration des Variables d'Environnement

Créez `.env.local` dans la racine du projet :

```bash
# API
NEXT_PUBLIC_API_URL=http://localhost:3001/api
NEXT_PUBLIC_API_TIMEOUT=10000

# Authentification
NEXT_PUBLIC_AUTH_URL=http://localhost:3000/auth

# Cloudinary (optionnel)
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=votre_cloud_name
NEXT_PUBLIC_CLOUDINARY_API_KEY=votre_api_key

# Monitoring/Logging
NEXT_PUBLIC_LOG_LEVEL=info

# Base de données (si applicable)
DATABASE_URL=postgresql://user:password@localhost/db_name
```

## 🎯 Premier Composant

Une fois intégré, vous pouvez créer votre première entité. Voici un exemple avec `users` :

```tsx
// src/app/users/page.tsx
"use client";

import { useUserList } from "@/lib/users/api/queries";
import { UserTable } from "@/lib/users/components/user-table";

export default function UsersPage() {
  const { data, isLoading, error } = useUserList({ page: 1, size: 20 });

  if (isLoading) return <div>Chargement...</div>;
  if (error) return <div>Erreur : {error.message}</div>;

  return (
    <div>
      <h1>Utilisateurs</h1>
      <UserTable data={data?.data} />
    </div>
  );
}
```

Voir le guide complet : [Guide des Entités](/entity-guide)

## 🔧 Dépannage Courant

### Erreur : "Cannot find module '@/lib'"

→ Assurez-vous que `jsconfig.json` ou `tsconfig.json` configure l'alias `@`:

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### Erreur : "QueryClient not found"

→ Vérifiez que `QueryProvider` enveloppe correctement votre app dans `layout.tsx`

### Erreur : "Toaster not found"

→ Vérifiez que `sonner` est installé et que `Toaster` est importé
